# Specifications
Use dark theme (dark gray)
Host Features:
1. Should be able to view every teams codes, lives, number of characters and oher details in realtime
2. Make the application more secure so nobody can find a loophole to exploit
3. Host should have the option to save every data (every team start time end time, final code, lives remaining, and other details if any) as an excel sheet
4. The host will accept the team only then the team join the room and the host should have the ability to kick a team from the room.
5. Ability to change team name, grant a life to a team and increase the time limit, or pause the timer.
6. Assign a pastel color to represent each team, then that color will be the theme for that team's UI
7. On the room creation page, the host should be able to specify the number of lives for teams too 
8. Accept or reject a code submitted, if the code is correct no life is decreased, but if code is rejected then reduce a life.
Redesign the host dashboard and the room creation page adding the above features, make sure the colors and fonts are consistent, save host data in the browser to prevent data loss due to accidental reloads

Players Features:
1. Players should not be able to paste anything in the text box.
2. When reloade the cursor should move to the end of the stored code.
3. Theme should change based on what the host chooses for the team.
4. Ending turn for each player on the team should submit the code but the team should not be able to see it yet, if the code is marked correct by the host then they can see the code and a success text(animation) or one life is deducted (add animation for that) and the game goes on.
5. Make the application more secure so nobody can find a loophole to exploit
6. As the time on the timer reaches the end change the color of the timer and the bar to yellow and then red (also can add shake animation on the timer in the last 10 seconds).
7. When a team joins, they go to a lobby and wait for the host to accept them before joining the room.
Redesign the player page adding the above features, make sure the colors are consistent, save the team color in the browser too if reloaded
